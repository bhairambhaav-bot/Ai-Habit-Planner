# ⚡ Hybrid AI Study Planner & Habit Loop Tracker (v3 - Fixed PDF Engine)

## 🛠️ Problem Solved:
1. **PDF.js Integration:** Browser me PDF ka readable text extract hoga, binary tokens (`0 obj`, `stream`) filter ho jayenge.
2. **Clean NLP Topic Decomposition:** Syllabus ke asali Units, Chapters aur Topics alag hokar clean study schedule banega.
3. **Backend `pypdf` Support:** Backend se bhi directly PDF parse hoti hai.

## 🚀 Run Karne Ka Tarika:
1. VS Code me `offline_ai_study_planner_v3` folder kholein.
2. Terminal kholein (`Ctrl + ~`) aur likhein:
   ```bash
   pip install -r requirements.txt
   python app.py
   ```
3. Browser me kholein: `http://localhost:5000` (ya `index.html` par double click karein).
4. Ab PDF upload karein — saaf-suthre topics aur schedule aayenge!
